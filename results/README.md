# Results

One page per run, the evidence is attached to the lab release.
Each row names a scenario in plain words; its links point at evidence
files named by scenario ID, listed in the [README](../README.md#scenario-groups).

A run of a plugin tag gets a page named `<lab tag>-plugin-<plugin tag>.md`,
with its evidence tarball attached to that lab release. A run on a lab commit that is not the tag keeps the tag in its name and says which commit on the page. A lab-release page
named `<lab tag>.md` is written only when the lab changed with no plugin run.
v0.1.0 has both pages; v0.2.0 has only the plugin page, because its one run
was against plugin v2.6.0-rc1.
